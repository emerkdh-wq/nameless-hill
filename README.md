# 무명고지 분대전

한국전쟁을 배경으로 한 실시간 분대 전술 게임입니다. 이름과 능력치가 있는 병사 6명을 이끌고 1950년 춘천부터 1953년 베티고지까지 실제 전투에 바탕한 작전 25개를 수행합니다.

**플레이:** https://emerkdh-wq.github.io/nameless-hill/

## 특징

- **병사 관리** — 병사마다 이름(수정 가능), 계급, 능력치 다섯 가지(체력·강인함·사격술·민첩성·경계, 1~10)가 있습니다. 작전이 끝나면 받는 훈련 점수로 원하는 병사의 능력치를 올립니다.
- **장비** — 총기, 탄창, 수류탄, 연막탄, 구급낭을 병사마다 정합니다. 체력에 따라 들 수 있는 무게가 정해지고, 무거울수록 느려지고 빨리 지칩니다.
- **전투** — 엄폐와 시야, 제압과 공황, 모퉁이 사격, 총검 백병전, 출혈과 응급처치, 총기 고장, 적과 아군의 무기 줍기가 있습니다.
- **사격 방식** — 정밀·일반·제압사격에 따라 명중률과 탄약 소모가 달라집니다.
- **분대장** — 출동하는 대원 중 계급이 가장 높은 병사가 자동으로 분대장이 되고 ★ 표시가 붙습니다. 분대장 곁의 대원은 제압을 절반 가까이 덜 받고 두 배 넘게 빨리 추스르며, 공황에 빠지지 않습니다.
- **손실** — 전사자와 실종자는 명부에 남고, 철수하면 쓰러진 병사는 포로가 됩니다. 「신병 충원」으로 빈자리를 채웁니다.

## 조작

| 입력 | 동작 |
|---|---|
| 왼쪽 클릭 / 끌기 | 병사 선택 |
| 오른쪽 클릭 | 이동, 적을 누르면 공격, 쓰러진 병사를 누르면 줍기·응급처치 |
| 1–6 | 병사 선택 (Shift: 추가) |
| Q / W / E | 전진 / 질주 / 포복 |
| Z / X / C | 정밀 / 일반 / 제압사격 |
| R | 장전 |
| G / V | 수류탄 / 연막탄 |
| F | 사격 중지 |
| S | 정지 |
| A | 전원 선택 |
| L | 조명탄 (야간) |
| Space | 일시정지 (정지 중에도 명령 가능) |

## 실행

빌드가 필요 없는 HTML 파일 하나입니다. `index.html`을 브라우저로 열면 됩니다. 진행 상황은 브라우저에 저장됩니다.

## 역사에 대하여

작전의 날짜, 장소, 참가 부대, 전투의 큰 흐름은 실제 기록을 따랐지만 지도와 적 배치는 게임에 맞게 꾸몄고, 플레이어의 분대는 가상의 부대입니다. 「오마치 고개」는 실제로는 돌파하지 못한 전투를 성공했다고 가정한 작전입니다.
